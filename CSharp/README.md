# CSharp

Danh mục mã C#, ví dụ API, Blazor và các đoạn mã hỗ trợ vận hành.

## Danh mục

Chưa có tệp mã C# chuyên biệt trong thư mục này. Khi thêm, nên có tệp mã và tài liệu Markdown giải thích mục tiêu, phiên bản .NET, cấu hình cần thiết, cách chạy và ví dụ đầu vào/đầu ra.

| Tệp | Mô tả |
|---|---|
| `TenChucNang.cs` | Mã nguồn hoặc ví dụ |
| `TenChucNang.md` | Cách dùng, phụ thuộc và lưu ý |

Không commit thông tin kết nối, API key hoặc secrets vào repository.
