# PowerShell

Danh mục script PowerShell cho tự động hóa quản trị Windows, triển khai phần mềm, tài khoản và mạng.

## Danh mục

Chưa có tệp script PowerShell nào được lưu trong thư mục này. Khi thêm script, cập nhật danh mục theo mẫu:

| Script | Mục đích | Quyền chạy | Hướng dẫn |
|---|---|---|---|
| `TenScript.ps1` | Mô tả ngắn chức năng | User/Admin | [Đọc hướng dẫn](TenScript.md) |

## Lưu ý

- Nêu rõ phiên bản PowerShell và quyền cần thiết.
- Kiểm tra nội dung trước khi chạy script có tác động đến máy hoặc tài khoản.
- Không lưu mật khẩu, token hay thông tin xác thực thật trong Git.
