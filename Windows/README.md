# Windows

Các script và hướng dẫn quản trị Windows: Registry, CMD, dịch vụ và domain.

## Danh mục

| Tài liệu | Mô tả | Tệp |
|---|---|---|
| **Clear Last Logon** | Xóa các giá trị Registry dùng hiển thị người đăng nhập gần nhất trên màn hình logon. Không xóa tài khoản Windows hoặc Event Log. | [Hướng dẫn](Clear-LastLogon.md) · [Script BAT](Clear-LastLogon.bat) |

## Lưu ý

- Đọc hướng dẫn trước khi chạy script sửa Registry.
- Script Clear-LastLogon cần chạy bằng quyền Administrator.
- Kiểm thử trên máy thử nghiệm trước khi áp dụng diện rộng.
