# SQL

Danh mục truy vấn SQL, PostgreSQL, hàm và các ghi chú thao tác cơ sở dữ liệu.

## Danh mục

Chưa có tệp truy vấn riêng trong thư mục này. Khi bổ sung, ghi rõ hệ quản trị CSDL, bảng liên quan, mục đích, tham số và ví dụ kết quả.

## Lưu ý an toàn

- Ưu tiên chạy truy vấn đọc để kiểm tra trước khi sửa dữ liệu.
- Với `UPDATE`/`DELETE`, xác nhận điều kiện `WHERE` và có phương án sao lưu/rollback.
- Không đưa dữ liệu cá nhân hoặc thông tin kết nối thật vào ví dụ công khai.
