# Network

Danh mục ghi chú và công cụ mạng: FortiGate, DNS, VPN, SD-WAN và xử lý sự cố kết nối.

## Danh mục

Chưa có tài liệu chuyên biệt nào trong thư mục này. Khi bổ sung, ghi rõ thiết bị/phạm vi áp dụng, lệnh kiểm tra, kết quả mong đợi và phương án quay lui.

| Chủ đề | Nội dung nên ghi |
|---|---|
| FortiGate | Chính sách, routing, traffic shaping/QoS |
| DNS | Tra cứu, phân giải và xử lý lỗi |
| VPN | Profile, route, split tunnel và kiểm tra kết nối |
| SD-WAN | Đường truyền, health-check và định tuyến |
